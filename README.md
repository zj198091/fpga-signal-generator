# 基于FPGA的可配置多波形信号发生器

## 开发与硬件平台
- 开发工具：Vivado 2022.2、MATLAB R2026b
- 硬件平台：AMD Artix-7 XC7A35T

## 核心功能与技术实现
本项目采用全Verilog RTL手写实现，自上而下模块化拆分，已完成综合、实现全流程，时序收敛，资源占用率低，下载比特流即可直接上板运行。

1.  **相位抖动优化DDS波形生成**
    核心采用带相位抖动优化的DDS架构，支持正弦波、方波、锯齿波、三角波四种标准波形。相位抖动通过16位LFSR实现，作用于相位截断低4位，实测1MHz正弦波SFDR可从60dB左右提升至68dB以上，杂散抑制效果明显。

2.  **可重构FIR数字滤波器**
    内置16阶可重构FIR滤波器，支持低通、带通、高通三种模式一键切换。滤波器系数由MATLAB设计，采用汉宁窗加窗、12位有符号数量化，滤波效果稳定。输出端通过一拍寄存器打拍消组合毛刺，时序更稳健。

3.  **按键交互与幅度调节**
    输出幅度支持256级连续可调，所有参数通过板载按键切换，集成20ms硬件消抖逻辑，可有效避免机械按键误触发。

4.  **模块化系统设计**
    工程按功能模块完整拆分，VGA双域显示逻辑已完成代码编写与功能仿真；当前硬件仅验证DAC输出通路，后续外接显示设备可直接例化启用，扩展性强。

配套MATLAB脚本可生成ROM系数、计算滤波器参数、测试SFDR指标，便于参数调整与结果复现。

## 关键性能指标
| 参数项 | 指标值 |
| ---- | ---- |
| 系统主时钟 | 100MHz |
| 波形类型 | 正弦波、方波、锯齿波、三角波 |
| 滤波模式 | 低通、带通、高通（16阶汉宁窗） |
| 幅度调节 | 256级连续可调 |
| 数据位宽 | 12位 |
| 正弦波SFDR | 优化后≥68dB（1MHz实测） |
| 核心芯片 | XC7A35T |

## 上板操作说明
- KEY0：循环切换波形类型
- KEY1：循环切换滤波模式
- KEY2：增大输出幅度
- KEY3：减小输出幅度

## 目录结构
- `rtl/`：核心Verilog源码，含FFT IP配置文件
- `coe/`：波形ROM初始化系数文件
- `constraint/`：FPGA引脚约束与时序约束文件
- `sim/`：各模块独立仿真testbench
- `matlab/`：波形生成、滤波器设计、SFDR计算辅助脚本
